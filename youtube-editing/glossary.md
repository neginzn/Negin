# واژه‌نامه

| انگلیسی | فارسی | توضیح |
|---|---|---|
| B-roll | تصاویر مکمل | تصویری که روی روایت می‌نشیند |
| J-Cut | جی-کات | صدای صحنهٔ بعد زودتر از تصویرش می‌آید |
| L-Cut | ال-کات | صدای صحنهٔ قبل بعد از تصویرش ادامه دارد |
| Ken Burns | کن برنز | زوم/حرکت آهسته روی عکس ثابت |
| Punch-in | پانچ‌این | جهش ناگهانی به نمای نزدیک‌تر |
| Parallax | پارالاکس | حرکت لایه‌ها با سرعت متفاوت (حس عمق) |
| Ducking | داکینگ | کم‌کردن خودکار موسیقی هنگام حرف‌زدن راوی |
| Room tone | اتاق‌تن | صدای خالی محیط ضبط |
| Drone (audio) | درون صوتی | بافت کشیدهٔ کم‌فرکانس برای تعلیق |
| LUFS | واحد لادنس | معیار بلندی ادراکی صدا |
| True Peak | پیک واقعی | بیشینهٔ واقعی سیگنال؛ برای جلوگیری از اعوجاج |
| Retention | ریتنشن / نگه‌داشت | درصد ماندگاری مخاطب |
| Cold open | شروع سرد | شروع بدون مقدمه و معرفی |
| Open loop | حلقهٔ باز | سؤالی که عمداً بی‌جواب می‌ماند |
| Redaction | ریداکشن / سانسور | پوشاندن اطلاعات حساس در سند |
| Proxy | پراکسی | نسخهٔ سبک فایل برای تدوین روان |
| Grade | گرید | تصحیح و طراحی رنگ |
| PowerGrade | پاورگرید | گرید ذخیره‌شده برای استفادهٔ مجدد |
| Fair Use | استفادهٔ منصفانه | دفاع حقوقی در برابر ادعای کپی‌رایت |
| FOIA | قانون آزادی اطلاعات | سازوکار دریافت اسناد عمومی در آمریکا |
| Content ID | کانتنت آی‌دی | سیستم شناسایی خودکار کپی‌رایت یوتیوب |
| Defamation | افترا | نسبت‌دادن ناروا و آسیب‌زننده به فرد |
