# فصل ۹ — گردش کار و خروجی

**قواعد نام‌گذاری:** بدون فاصله، بدون کاراکتر فارسی در نام فایل (بعضی نرم‌افزارها مشکل دارند)، با پیشوند شماره‌دار:
`bodycam_01_interrogation_part1.mp4`

## تنظیمات پروژه

- **رزولوشن:** `1920×1080` برای شروع؛ اگر منابع ۴K دارید، `3840×2160`.
- **نرخ فریم:** `24fps` (حس سینمایی/مستند) یا `30fps` (اگر بیشتر فوتیج شما ۳۰ است).
  ⚠️ **یک بار انتخاب کنید و برای همیشه در کانال ثابت نگه دارید.**
- **Color Science:** `DaVinci YRGB Color Managed`، Timeline: `Rec.709 Gamma 2.4`.
- **فوتیج با نرخ فریم متفاوت:** در تنظیمات پروژه گزینهٔ `Retime and Scaling` را روی `Optical Flow` بگذارید تا تبدیل نرم شود.

## پراکسی: چطور با سیستم ضعیف ۴K تدوین کنیم

1. همهٔ کلیپ‌ها را در Media Pool انتخاب کنید.
2. راست‌کلیک → `Generate Proxy Media` (رزولوشن نصف یا یک‌چهارم).
3. در منوی Playback → `Proxy Handling` → `Prefer Proxies`.
4. هنگام خروجی، Resolve خودکار به فایل اصلی برمی‌گردد.

اگر پراکسی کافی نبود: `Render Cache` را روی `Smart` بگذارید (منوی Playback).

## گردش کار پیشنهادی (ترتیب کار اهمیت دارد)

```
۱. تحقیق و جمع‌آوری منابع  →  sources.md
۲. نوشتن اسکریپت دو ستونه (متن | تصویر)
۳. ضبط روایت
۴. تمیزکردن و چیدن روایت روی تایم‌لاین  ← ستون فقرات
۵. «کات رادیویی»: فقط صدا، بدون تصویر، تا وقتی ریتم درست شود
۶. چیدن تصویر روی روایت
۷. گرافیک و متن
۸. طراحی صدا و میکس
۹. گرید رنگ
۱۰. زیرنویس
۱۱. بازبینی نهایی و خروجی
```

⚠️ **مرحلهٔ ۵ را رد نکنید.** اگر «کات رادیویی» بدون تصویر جذاب و روان باشد، ویدئوی نهایی تضمینی خوب است. اگر نباشد، هیچ گرافیکی نجاتش نمی‌دهد.

## تنظیمات دقیق خروجی برای یوتیوب

در صفحهٔ **Deliver**، پریست `YouTube` را بردارید و این‌ها را چک کنید:

| تنظیم | مقدار |
|---|---|
| Format | MP4 |
| Codec | H.264 (سازگارترین) یا H.265 برای ۴K |
| رزولوشن | همان رزولوشن تایم‌لاین |
| نرخ فریم | همان نرخ فریم تایم‌لاین |
| Quality | `Restrict to` — ۱۵–۲۰ Mb/s برای 1080p، ۴۰–۵۰ Mb/s برای ۴K |
| Encoding Profile | High |
| Key Frames | Automatic |
| Audio Codec | AAC، ۳۲۰ kb/s، ۴۸kHz، استریو |
| Loudness | ‎-۱۴ LUFS، True Peak حداکثر ‎-۱ dBTP |

**نکتهٔ عملی مهم:** حتی اگر ویدئوی شما 1080p است، **آپلود در ۴K کیفیت بصری بهتری در یوتیوب می‌دهد**، چون یوتیوب برای ویدئوهای ۴K کدک بهتری (VP9/AV1) اختصاص می‌دهد. اگر گرافیک و متن زیاد دارید، این تفاوت دیده می‌شود.

## بکاپ: قانون ۳-۲-۱

- **۳** نسخه از داده
- روی **۲** نوع رسانهٔ مختلف
- **۱** نسخه در مکان دیگر (ابر یا هارد بیرونی)

در این ژانر، فوتیجی که با FOIA گرفته‌اید یا سند نایابی که پیدا کرده‌اید، **قابل بازتولید نیست**. از دست دادنش یعنی از دست دادن کل پروژه.

همچنین: در Resolve مسیر `File → Project Settings → Auto Save` را روشن کنید و هر هفته `File → Export Project Archive` بگیرید.

## تمرین فصل

ساختار پوشهٔ بالا را به‌عنوان یک **تمپلیت خالی** روی دیسک بسازید و هر بار با کپی‌کردن آن پروژهٔ جدید را شروع کنید. همچنین یک `Project Template` در Resolve با تنظیمات پروژه، تمپلیت‌های گرافیکی و پاورگرید خود ذخیره کنید.
