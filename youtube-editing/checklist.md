# چک‌لیست قبل از انتشار

## محتوا و اخلاق
- [ ] نام قربانی درست تلفظ و نوشته شده؟
- [ ] قربانی به‌عنوان یک انسان معرفی شده، نه فقط یک پرونده؟
- [ ] دربارهٔ افراد محکوم‌نشده از زبان قطعی استفاده نکرده‌ام؟
- [ ] نظریه‌های شخصی صریحاً به‌عنوان نظریه معرفی شده‌اند؟
- [ ] اگر خانوادهٔ قربانی این را ببیند، آزرده نمی‌شود؟

## حقوقی
- [ ] `sources.md` کامل است و همهٔ لایسنس‌ها ثبت شده؟
- [ ] فوتیج خبری کوتاه است و روی آن تحلیل دارم؟
- [ ] موسیقی لایسنس معتبر دارد؟
- [ ] نام شاهدان، آدرس، پلاک و چهرهٔ افراد بی‌گناه سانسور شده (به‌صورت flatten، نه لایهٔ رویی)؟

## درآمدزایی
- [ ] هیچ تصویر گرافیکی خشونت/جسد وجود ندارد؟
- [ ] تامبنیل شوکه‌کننده یا اغراق‌آمیز نیست؟
- [ ] فرم خوداظهاری را صادقانه پر می‌کنم؟
- [ ] هشدار محتوا و منابع کمک در توضیحات هست؟

## فنی — تصویر
- [ ] هیچ تصویر ثابتی بیش از ۵ ثانیه بدون حرکت نمانده؟
- [ ] همهٔ متن‌ها حداقل ۱.۵ برابر زمان خواندن روی صفحه هستند؟
- [ ] متن‌ها ۵٪ از لبه‌ها فاصله دارند؟
- [ ] گرید همهٔ منابع یکدست است؟
- [ ] در Scope، لوما بین ۰ تا ۱۰۰ IRE است؟

## فنی — صدا
- [ ] ‎-۱۴ LUFS یکپارچه؟
- [ ] True Peak زیر ‎-۱ dBTP؟
- [ ] داکینگ در همهٔ نقاط درست عمل می‌کند (بخصوص سکوت‌های عمدی)؟
- [ ] هیچ‌جا سکوت دیجیتال مطلق نیست (اتاق‌تن وجود دارد)؟
- [ ] کل ویدئو را با هدفون کامل گوش کرده‌ام؟

## انتشار
- [ ] قلاب در ۱۵ ثانیهٔ اول وعده را مشخص می‌کند؟
- [ ] تامبنیل در ابعاد کوچک موبایل خوانا است؟
- [ ] عنوان با قلاب و تامبنیل هماهنگ است؟
- [ ] فایل `.srt` زیرنویس آپلود شده؟
- [ ] فصل‌بندی (Chapters) در توضیحات اضافه شده؟
- [ ] یک بار روی موبایل کامل دیده‌ام؟
