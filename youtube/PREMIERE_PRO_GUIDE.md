# راهنمای ادیت با Premiere Pro برای کانال True Crime بدون چهره

> مخصوص کانال Stranger Files: روایت + فوتیج و عکس آرشیوی + متن روی تصویر + موسیقی تاریک.

---

## ۱. تنظیمات پروژه
- **ویدیوی بلند:** Sequence با ابعاد 1920×1080، 30fps (یا 23.976 برای حس سینمایی)
- **شورت:** Sequence با ابعاد 1080×1920، 30fps
- **ساختار پوشه‌ها در Project panel:** `01_Voice` · `02_Footage` · `03_Photos` · `04_Music_SFX` · `05_Graphics`
- **Proxy:** برای فوتیج 4K، روی کلیپ‌ها راست‌کلیک ← Proxy ← Create Proxies. ادیت روی آیپد یا لپ‌تاپ ضعیف را روان می‌کند.

## ۲. ترتیب ادیت (Workflow)
1. **صدای راوی را اول بچین** (ترک A1). کل ادیت دور صدا ساخته می‌شود.
2. **سکوت‌ها و اشتباه‌ها را ببر:** ابزار Razor (C)، یا Text-Based Editing (Window ← Text ← Transcribe، بعد متن را پاک کن تا ویدیو هم بریده شود).
3. **B-roll را روی V1 و V2 بگذار:** برای هر جمله یک تصویر. هر تصویر **۲ تا ۵ ثانیه** در ویدیوی بلند و **۱ تا ۲ ثانیه** در شورت.
4. **متن‌ها روی V3:** تاریخ، اسم، مکان و نقل‌قول‌ها.
5. **موسیقی روی A2 و افکت صوتی (SFX) روی A3.**
6. **رنگ:** Lumetri Color (پایین‌تر).
7. **صدا:** Essential Sound (پایین‌تر).
8. **Export**

## ۳. حرکت روی عکس‌ها (Ken Burns)
- کلیپ را انتخاب کن ← Effect Controls ← **Scale** و **Position**
- در ابتدای کلیپ یک keyframe بگذار (Scale 100)، در انتها یک keyframe دیگر (Scale 110 تا 115)
- راست‌کلیک روی keyframeها ← **Ease In / Ease Out** تا حرکت نرم شود
- برای هیجان بیشتر: یک **Punch-in** سریع (Scale از 100 به 108 در ۴ تا ۶ فریم) روی جمله‌ی مهم

## ⭐ اصل سبک کانال (بازخورد صاحب کانال)
مستند سینمایی و **خوددار**. ترنزیشن‌های glitch، flash و whip، افکت صوتی whoosh و boom، متن pop و لرزش مصنوعی حس «گیم» می‌دهند و ترس را از بین می‌برند. زیرنویس و متن روی تصویر را هم‌زمان نگذار. حرکت فقط **زوم یا پن آهسته**. جدول پایین را با همین اصل بخوان: گزینه‌های Glitch و Film Burn را فقط در موارد خیلی خاص استفاده کن.

## ۴. ترنزیشن‌ها (کم و هدفمند)
| ترنزیشن | کجا |
|---|---|
| **Hard cut** (بدون ترنزیشن) | ۸۰٪ برش‌ها. سریع‌ترین و حرفه‌ای‌ترین |
| **Dip to Black** (۸ تا ۱۲ فریم) | بین فصل‌ها، یا بعد از یک جمله‌ی شوکه‌کننده |
| **Cross Dissolve** (۱۰ تا ۱۵ فریم) | گذر زمان («سه سال بعد…») |
| **Film Burn / Light Leak** (overlay با Blend Mode: Screen) | شروع فصل‌ها، برای حس آرشیوی |
| **Glitch یا VHS** (overlay) | لحظه‌ی کشف، فوتیج دوربین مداربسته |

❌ ترنزیشن‌های چرخشی، 3D و Push زیادی حس آماتوری می‌دهند.
⚠️ **ویدیو را با Dip to Black یا محو شدن از سیاه شروع نکن.** فریم اول باید تصویر قوی داشته باشد (درس شورت Kemper).

## ۵. متن و گرافیک (Essential Graphics)
- فونت‌ها: **Anton** یا **Bebas Neue** برای تیتر، **Courier / Special Elite** برای حس پرونده‌ی پلیسی
- رنگ‌ها: سفید + **قرمز (#E11E1E)** برای تأکید. سیاه‌وسفید با یک رنگ قرمز = امضای کانال
- یک **Lower third** ثابت برای تاریخ و مکان بساز و در Essential Graphics به‌عنوان **.mogrt** ذخیره کن تا هر بار آماده باشد
- متن‌های مهم را با انیمیشن Scale یا Opacity در ۶ تا ۸ فریم وارد کن
- **ناحیه‌ی امن شورت:** متن را از ۲۵۰ پیکسل پایینی و ۱۲۰ پیکسل سمت راست دور نگه دار (دکمه‌های یوتیوب)

## ۶. رنگ (Lumetri Color): حس آرشیوی و سرد
- Basic Correction: Contrast +15 تا +25، Highlights −10، Blacks −10
- Creative: Saturation 70 تا 80، یا 0 برای سیاه‌وسفید. Faded Film 10 تا 20
- Vignette: Amount −1.5 تا −2.5
- افزودن نویز فیلم: Effects ← Noise (5 تا 8٪) یا overlay فیلم ۱۶ میلی‌متری
- یک **Adjustment Layer** بالای همه‌ی ترک‌ها بگذار و Lumetri را روی آن اعمال کن تا کل ویدیو یکدست شود

## ۷. صدا (مهم‌ترین بخش ریتنشن)
- **Essential Sound:** صدای راوی ← **Dialogue** ← Enhance Speech (یا Loudness ← Auto-Match)
- موسیقی ← **Music** ← **Ducking** روشن (Duck against Dialogue، −15 تا −20 dB). موسیقی زیر صدا خودکار کم می‌شود
- **بلندی نهایی:** راوی حدود **−14 LUFS** (استاندارد یوتیوب). موسیقی زیر صدا −28 تا −32
- **SFX:** Whoosh روی برش‌های مهم، Riser قبل از افشاگری، Boom یا Hit روی جمله‌ی شوکه‌کننده، صدای تایپ روی متن‌ها
- موسیقی و SFX فقط از منابع دارای مجوز: YouTube Audio Library، Epidemic Sound، Artlist

## ۸. زیرنویس
- Window ← Text ← Captions ← **Transcribe sequence** ← **Create captions**
- برای شورت: ۱ تا ۳ کلمه در هر خط، وسط پایین صفحه، فونت ضخیم با outline سیاه
- برای ویدیوی بلند: فایل **SRT** را جدا Export و در YouTube Studio آپلود کن (به سئو کمک می‌کند)

## ۹. ساختار ویدیوی بلند (بر اساس داده‌ی کانال)
- **۰ تا ۳۰ ثانیه:** قوی‌ترین تصویر یا فوتیج + جمله‌ی شوک + وعده. بدون لوگو و اینترو
- **هر ۳۰ تا ۶۰ ثانیه:** تغییر بصری (عکس جدید، نقشه، متن، زوم)
- **مارکرها (M):** برای هر فصل یک مارکر بگذار و اسمش را بنویس. بعد از Export، فصل‌بندی توضیحات یوتیوب را از روی همین مارکرها بنویس
- **۲۰ ثانیه‌ی آخر:** فضای خالی یا تصویر آرام برای **End screen** (دو ویدیو + Subscribe)

## ۱۰. Export
- **ویدیوی بلند:** File ← Export ← Media ← H.264 ← Preset: **YouTube 1080p Full HD**، VBR 2-pass، Target 12 تا 16 Mbps، صدا AAC 320kbps
- **شورت:** همان تنظیمات با 1080×1920
- تیک **Use Maximum Render Quality** برای عکس‌هایی که زوم می‌شوند

## ۱۱. میان‌برهای ضروری
| کلید | کار |
|---|---|
| C | Razor (برش) |
| V | Selection |
| Q / W | برش و حذف تا ابتدای یا انتهای کلیپ از روی نشانگر (Ripple Trim) |
| Ctrl/Cmd + K | برش همه‌ی ترک‌ها در محل نشانگر |
| Shift + Delete | Ripple Delete |
| M | Marker |
| Ctrl/Cmd + D | ترنزیشن پیش‌فرض ویدیو |
| Shift + Ctrl/Cmd + D | ترنزیشن پیش‌فرض صدا |
| J / K / L | عقب / توقف / جلو |

## ۱۲. قالب (Template) برای سرعت
یک پروژه‌ی **Template** با این‌ها بساز و هر بار از آن کپی بگیر:
- Adjustment Layer با Lumetri و Vignette
- Lower third ذخیره‌شده (.mogrt)
- overlayهای Film grain و Light leak
- پوشه‌ی SFX و موسیقی‌های پرکاربرد

## همکاری با Claude
Claude نمی‌تواند Premiere Pro را روی دستگاه صاحب کانال اجرا کند. ولی این کارها را می‌کند:
1. **ادیت کامل با ffmpeg:** عکس و فوتیج و صدا را بگیرد، برش، زوم، متن، ترنزیشن، موسیقی و ducking را اعمال کند و MP4 نهایی بدهد (مثل شورت‌های Kemper و Hearst). این روش برای شورت‌ها و ویدیوهای عکس‌محور مناسب است.
2. **ساخت فایل XML تایم‌لاین** (Final Cut Pro 7 XML) که در Premiere با File ← Import باز شود و کلیپ‌ها از قبل روی تایم‌لاین چیده شده باشند.
3. **Shot list و اسکریپت زمان‌بندی‌شده** برای هر بخش ویدیو.
4. **گرافیک‌ها** (تامبنیل، Lower third، کارت عنوان فصل‌ها) به‌صورت PNG آماده.

محدودیت: فایل‌های ویدیویی خیلی حجیم (مثلاً فوتیج خام ۲۰ دقیقه‌ای) ممکن است برای آپلود در چت سنگین باشند.
