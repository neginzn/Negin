# ۲. دیگنیتی‌ها (قوت و ضعف سیارات) و فرقه

یک استرولوژر حرفه‌ای همیشه دو سؤال می‌پرسد:
1. **سیاره چقدر «خوب» عمل می‌کند؟** ← دیگنیتی ذاتی (Essential) + سعد/نحس + فرقه
2. **سیاره چقدر «قدرت/نمود» دارد؟** ← دیگنیتی عَرَضی (Accidental): خانهٔ زاویه‌ای، سرعت، رؤیت…

## ۲.۱ دیگنیتی ذاتی (Essential Dignities)

| مرتبه | امتیاز (لیلی) | معنا |
|---|---|---|
| خانه/بیت (Domicile) | +۵ | صاحب‌خانه؛ کنترل کامل، منابع کافی |
| شرف (Exaltation) | +۴ | مهمان عزیز؛ تکریم، گاهی اغراق |
| مثلثه (Triplicity) | +۳ | حمایت خانواده/گروه، بخت |
| حد (Term/Bound) | +۲ | تنها کمی ابزار |
| وجه (Face/Decan) | +۱ | «ترسیده اما محترم» |
| وبال (Detriment) | −۵ | در خانهٔ مقابل خود؛ کار برخلاف طبیعت |
| هبوط (Fall) | −۴ | در مقابل شرف؛ بی‌اعتبار، تحقیر |
| غریب (Peregrine) | (−۵ در لیلی) | بدون هیچ دیگنیتی؛ سرگردان |

**ترتیب کلدانی:** زحل ← مشتری ← مریخ ← خورشید ← ونوس ← عطارد ← ماه (از کند به سریع). همین ترتیب در ساعات سیاره‌ای، روزهای هفته و زیردوره‌های فرداریا استفاده می‌شود.

**دکان مدرن (مثلثه‌ای):** دکان اول = حاکم خود نشانه، دوم = حاکم نشانهٔ بعدی همان عنصر، سوم = سومی (مثلاً حمل: مریخ، خورشید، مشتری).

## ۲.۲ دیگنیتی عَرَضی (Accidental)
| عامل | قوی | ضعیف |
|---|---|---|
| خانه | زاویه‌ای (۱، ۱۰ بیشترین؛ سپس ۷، ۴)، ۱۱، ۵ | ۱۲، ۶، ۸ |
| حرکت | مستقیم، سریع‌تر از میانگین | راجع، کند، در ایستگاه (ایستگاه = تمرکز شدید، مبهم) |
| نسبت به خورشید | **صمیم/کازیمی (Cazimi)**: تا ۱۷′ از مرکز خورشید = بسیار قوی | **احتراق (Combust)**: تا ۸°۳۰′ = ضعیف، پنهان؛ **زیر شعاع (Under the beams)**: تا ۱۵° |
| شرقی/غربی | سیارات بالایی (مریخ/مشتری/زحل) شرقی خورشید (طلوع پیش از خورشید) قوی‌ترند؛ ونوس/عطارد غربی (عصرگاهی) | |
| ماه | افزایشی در نور، سریع | کاهشی، «راه سوخته» (Via Combusta: ۱۵° میزان تا ۱۵° عقرب)، خالی‌السیر (Void of Course) |

| ستارگان | مقارنه با رگولوس، اسپیکا | مقارنه با الگول |
| شادمانی | در خانهٔ شادی خود (عطارد ۱، ماه ۳، ونوس ۵، مریخ ۶، خورشید ۹، مشتری ۱۱، زحل ۱۲) | |
| هیز (Hayz) | سیارهٔ روزانهٔ مذکر در چارت روز، بالای افق، در نشانهٔ مذکر (و برعکس برای شبانه‌ها) | |

## ۲.۳ فرقه (Sect) — مهم‌ترین تمایز در استرولوژی سنتی
- **چارت روز (Diurnal):** خورشید بالای افق (خانه‌های ۷ تا ۱۲). **چارت شب:** خورشید زیر افق (۱ تا ۶).
- **فرقهٔ روز:** خورشید (نور)، مشتری (سعد فرقه)، زحل (نحس فرقه). **فرقهٔ شب:** ماه (نور)، ونوس (سعد فرقه)، مریخ (نحس فرقه). عطارد: صبحگاهی = روز، عصرگاهی = شب.

| | چارت روز | چارت شب |
|---|---|---|
| سودمندترین سعد | مشتری | ونوس |
| سعد کمتر | ونوس | مشتری |
| نحس مهارشده | زحل (سختی سازنده) | مریخ (انرژی سازنده) |
| **نحس خارج از فرقه** (مشکل‌سازترین) | **مریخ** | **زحل** |
| نور فرقه (Sect Light) | خورشید | ماه |

این تمایز در پروفکشن، فرداریا، سولار ریترن و ترانزیت‌ها مستقیماً به کار می‌رود: ترانزیت/فعال‌شدن نحس خارج از فرقه معمولاً سخت‌تر است.

## ۲.۴ آلمُتن (Almuten) و کدخدا و هیلاج
- **آلمُتن یک درجه:** سیاره‌ای با بیشترین امتیاز دیگنیتی ذاتی در آن درجه.
- **آلمُتن چارت (Almuten Figuris):** جمع امتیاز روی نقاط اصلی (ASC، MC، خورشید، ماه، سعادت، اجتماع/استقبال پیش از تولد) ← سیارهٔ غالب شخصیت.
- **هیلاج (Hyleg/Apheta):** «دهندهٔ حیات»؛ معمولاً نور فرقه اگر در خانهٔ مناسب باشد، وگرنه نور دیگر، سعادت، طالع.
- **کدخدا (Alcocoden):** سیارهٔ حاکم هیلاج که سال‌های عمر را می‌دهد (سال‌های بزرگ/میانه/کوچک). – تکنیک طول عمر؛ امروز با احتیاط و غیرپیشگویانه استفاده شود.
