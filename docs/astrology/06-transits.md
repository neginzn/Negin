# ۶. ترانزیت‌ها (Transits / عبورها)

## ۶.۱ اصول
**ترانزیت = موقعیت فعلی سیارات در آسمان نسبت به چارت تولد.** دو نوع اثر:
1. **عبور از خانه‌های تولد** ← حوزهٔ فعال (زمینه).
2. **جنبه به سیارات/نقاط تولد** ← رویداد (محرک). مهم‌ترین: مقارنه، مقابله، تربیع؛ سپس تثلیث و تسدیس.

### سلسله‌مراتب اهمیت
- **سیارات کند (Outer) = رویدادهای بزرگ و دوره‌ای:** پلوتو، نپتون، اورانوس (ماه‌ها تا ۲ سال، اغلب سه‌بار تماس: مستقیم–رجعت–مستقیم)، زحل (چند ماه)، مشتری (چند هفته تا ماه).
- **سیارات سریع = ماشه (Trigger):** مریخ (روزها)، خورشید/عطارد/ونوس (۱–۳ روز)، ماه (چند ساعت). وقتی سیارهٔ سریع به همان نقطه‌ای می‌رسد که سیارهٔ کند در حال لمس است ← رویداد دقیق.
- **نقاط حساس:** ASC، MC، DSC، IC، نیّرین، حاکم طالع، ارباب سال، سهم سعادت. ترانزیت به **محورها** قوی‌ترین است.
- **قاعدهٔ وعده:** «ترانزیت چیزی را می‌آورد که چارت تولد وعده داده باشد.» ترانزیت بدون پشتوانهٔ تولد/پروفکشن/ریترن اثر کوچکی دارد.
- **قاعدهٔ لایه‌ها (حرفه‌ای):** پیش‌بینی وقتی قطعی است که هم‌زمان (۱) دورهٔ بلندمدت (فرداریا/داشا/ZR)، (۲) پروفکشن/ارباب سال، (۳) سولار ریترن و (۴) ترانزیت/پروگرشن همه به یک موضوع اشاره کنند.

### اُرب و زمان‌بندی
- اُرب ترانزیت: ۱° (برای دقیق)، تا ۳° برای سیارات بیرونی (دورهٔ «در حال اثر»).
- **ایستگاه‌ها** روی نقطهٔ تولد بسیار قوی‌اند.
- **کسوف و خسوف (Eclipses)** روی نقاط تولد (اُرب ~۳°، برای محورها/نیّرین) ← رویدادهای سرنوشت‌ساز تا ۶ ماه. محور گره‌ها مشخص می‌کند کدام محور خانه‌ای درگیر است (در ۲۰۲۶–۲۰۲۷: محور دلو–اسد).
- **ورود به نشانه (Ingress)** و **ورود به خانهٔ Whole Sign** = تغییر فصل زندگی.

## ۶.۲ معنای ترانزیت هر سیاره (به سیاره/نقطهٔ تولد)
| ترانزیت | ماهیت | مدت تقریبی |
|---|---|---|
| **ماه** | حال‌وهوا، روزمره، رویدادهای کوچک | ساعات |
| **خورشید** | تمرکز، دیده‌شدن، انرژی برای همان موضوع | ۲–۳ روز |
| **عطارد** | پیام، تماس، سفر کوتاه، قرارداد، تصمیم | ۱–۳ روز (رجعت: تکرار) |
| **ونوس** | عشق، لذت، پول، صلح، هنر | ۲–۴ روز |
| **مریخ** | اقدام، تعارض، حرارت، جراحی/حادثه، انگیزه | ~۱ هفته |
| **مشتری** | رشد، فرصت، فراوانی، سفر، آموزش، گاهی افراط | ۲–۶ هفته (سه‌گانه تا ۵ ماه) |
| **زحل** | آزمون، ساختار، مسئولیت، تأخیر، کاهش، بلوغ، پایان‌های لازم | ۱–۱۰ ماه |
| **اورانوس** | ناگهان، آزادی، شکستن قالب، تغییر غیرمنتظره، بیداری | ~۱ سال |
| **نپتون** | انحلال، ابهام، الهام، فریب، معنویت، فداکاری | ۱–۲ سال |
| **پلوتو** | قدرت، بحران، مرگ/تولد دوباره، وسواس، تحول ریشه‌ای | ۱–۲.۵ سال |
| **گره‌ها** | پیوندهای سرنوشت، ورود/خروج افراد | ماه‌ها |
| **کایرون** | زخم/شفا، آموزش از درد | ماه‌ها |

### ترکیب‌های کلیدی (سیارهٔ ترانزیتی ← سیارهٔ تولد)
- **زحل ← خورشید:** کاهش انرژی، مسئولیت، فشار از اقتدار، بازتعریف هویت.
- **زحل ← ماه:** افسردگی/خستگی، مسائل خانوادگی و خانه، مسئولیت مراقبت.
- **زحل ← ونوس:** آزمون رابطه، تعهد یا جدایی، تنگی مالی.
- **زحل ← ASC:** بدن، تصویر، مسئولیت شخصی (مقارنه با ASC = شروع چرخهٔ ۲۹ساله).
- **زحل ← MC:** اوج یا سقوط حرفه بر اساس آنچه ساخته شده.
- **مشتری ← خورشید/ASC/MC:** موفقیت، شناخت، ارتقا.
- **مشتری ← ونوس:** عشق و پول.
- **اورانوس ← ونوس:** عشق ناگهانی/جدایی ناگهانی.
- **اورانوس ← ماه:** اسباب‌کشی، تغییر خانواده.
- **اورانوس ← MC:** تغییر شغل ناگهانی.
- **نپتون ← خورشید:** گم‌گشتگی هویت، الهام، خستگی، نیاز به مرز.
- **پلوتو ← ماه:** تحول عاطفی/خانوادگی عمیق.
- **پلوتو ← MC:** قدرت یا بحران حرفه‌ای.
- **مریخ ← مریخ/خورشید/ASC:** آغاز پروژه یا درگیری.

## ۶.۳ عبور سیارات کند از خانه‌های تولد (Whole Sign)
| خانه | مشتری (~۱ سال) | زحل (~۲.۵ سال) |
|---|---|---|
| 1 | اعتمادبه‌نفس، فرصت شخصی، افزایش وزن | بلوغ، مسئولیت شخصی، خستگی، بازتعریف خود |
| 2 | افزایش درآمد/خرج | کنترل مالی، کاهش یا ساختن پایدار پول |
| 3 | یادگیری، نوشتن، سفرهای کوتاه | مطالعهٔ جدی، مسئولیت در قبال خواهر/برادر |
| 4 | خانهٔ بزرگ‌تر، خانواده | تعمیر/ترک خانه، مسئولیت والدین |
| 5 | عشق، فرزند، خلاقیت | جدی شدن عشق، مسئولیت فرزند |
| 6 | کار بیشتر، بهبود سلامت | فشار کاری، مراقبت سلامت |
| 7 | رابطه/ازدواج، شراکت | تعهد یا آزمون رابطه، قراردادهای جدی |
| 8 | ارث، وام، پول همسر | بدهی، مالیات، بحران‌ها |
| 9 | سفر، تحصیل، مهاجرت | تحصیل جدی، آزمون باورها |
| 10 | ارتقا، شهرت | اوج حرفه یا بازسازی آن |
| 11 | دوستان، حامیان | گزینش دوستان، مسئولیت گروهی |
| 12 | حفاظت پنهان، معنویت | انزوا، پایان چرخه، پاکسازی |

اورانوس/نپتون/پلوتو در هر خانه: سال‌ها همان موضوع را دگرگون/مبهم/عمیق می‌کنند.

## ۶.۵ وضعیت آسمان ۲۰۲۶–۲۰۲۷ (برای ترانزیت‌های جمعی)
- **نپتون** وارد حمل (۲۶ ژانویه ۲۰۲۶) ← دوره‌ای ~۱۴ساله؛ **زحل** وارد حمل (۱۴ فوریه ۲۰۲۶) ← مقارنهٔ زحل–نپتون در ~۰–۱° حمل (فوریه ۲۰۲۶): پایان/آغاز چرخهٔ ۳۶ساله.
- **اورانوس** وارد جوزا (۲۶ آوریل ۲۰۲۶) تا ~۲۰۳۲–۲۰۳۳.
- **پلوتو** در دلو (تا ~۲۰۴۳).
- **مشتری** در اسد (۳۰ ژوئن ۲۰۲۶ تا ۲۶ ژوئیه ۲۰۲۷)، سپس سنبله.
- **محور گره‌ها:** گره شمالی در دلو (از ژوئیه ۲۰۲۶ با True Node) ← کسوف‌ها در محور اسد–دلو.
- **ونوس رجعی:** ۳ اکتبر تا ۱۴ نوامبر ۲۰۲۶ (۸°۳۰′ عقرب ← ۲۲°۵۴′ میزان).
- **مریخ رجعی:** ۱۰ ژانویه تا ۱ آوریل ۲۰۲۷ (۱۰° سنبله ← ۲۱° اسد).
- **عطارد رجعی ۲۰۲۶:** ۲۶ فوریه–۲۰ مارس (حوت)، ۲۹ ژوئن–۲۳ ژوئیه (سرطان)، ۲۴ اکتبر–۱۳ نوامبر (عقرب).
- **کسوف‌ها:** ۱۷ فوریه ۲۰۲۶ (۲۸°۵۰′ دلو)، ۱۲ اوت ۲۰۲۶ (۲۰° اسد)، ۶ فوریه ۲۰۲۷ (۱۷°۳۸′ دلو)، ۲ اوت ۲۰۲۷ (۹°۵۴′ اسد). **خسوف‌ها:** ۳ مارس ۲۰۲۶ (۱۲°۵۴′ سنبله)، ۲۸ اوت ۲۰۲۶ (۴°۵۴′ حوت)، ۲۰ فوریه ۲۰۲۷ (۲° سنبله)، ۱۸ ژوئیه ۲۰۲۷ (۲۶° جدی)، ۱۷ اوت ۲۰۲۷ (۲۴° دلو).
