# ابزارهای تدوین خودکار

## `montage.py` — مونتاژ عکس هماهنگ با صدا

عکس‌ها را با حرکت نرم زوم (کن برنز) روی صدای روایت می‌چیند و یک MP4 آمادهٔ یوتیوب تحویل می‌دهد.

```bash
python3 tools/montage.py --images ./photos --audio vo.m4a --out final.mp4 --grade
```

### چه کارهایی انجام می‌دهد
- **HEIC آیفون** را خودکار تبدیل می‌کند و چرخش EXIF را درست می‌کند
- عکس **عمودی** را وسط قاب با **پس‌زمینهٔ بلور** می‌گذارد (به‌جای نوار سیاه)
- زوم **این/اوت یک‌درمیان** + پن ملایم، تا حرکت یکنواخت و خسته‌کننده نشود
- دیزالو نرم بین عکس‌ها
- طول ویدئو را **دقیقاً** اندازهٔ صدا می‌کند
- صدا: هایپس ۸۰Hz، نویز ریداکشن، کمپرسور، و **لادنس دومرحله‌ای روی ‎-14 LUFS / ‎-1 dBTP**
- با `--music`: موسیقی پس‌زمینه با **داکینگ خودکار** زیر روایت

### گزینه‌های مهم

| گزینه | کار |
|---|---|
| `--grade` | لوک مستند (کم‌اشباع، سایهٔ سرد، وینیت ظریف) |
| `--shots FILE` | زمان‌بندی دستی هر عکس، به‌جای تقسیم مساوی |
| `--zoom 0.12` | شدت زوم؛ ۰.۰۸ آرام‌تر، ۰.۱۸ محسوس‌تر |
| `--xfade 0.7` | مدت دیزالو بین عکس‌ها |
| `--music FILE` | موسیقی پس‌زمینه با داکینگ |
| `--size 1080x1920` | خروجی عمودی برای شورتز |
| `--no-denoise` | وقتی صدا از قبل تمیز است |

### فایل زمان‌بندی دستی (`shots.txt`)
هر خط: نام عکس، خط عمودی، مدت به ثانیه.
```
01.jpg | 8
02.jpg | 5.5
03.heic | 12
```

### ترتیب عکس‌ها
بر اساس نام فایل مرتب می‌شود (`01`, `02`, `10` درست مرتب می‌شوند).
پس نام‌گذاری شماره‌دار = ترتیب دلخواه شما.

### نیازمندی‌ها
`ffmpeg` · `python3` · `pip install pillow pillow-heif`
