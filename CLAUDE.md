# CLAUDE.md

This repository is a YouTube growth knowledge base (primarily in Persian).

## Rules for Claude
- Before any YouTube-related task (video ideas, titles, thumbnails, scripts, hooks, descriptions, tags, Shorts, channel strategy, analytics review), read and apply `youtube/YOUTUBE_GUIDE.md`.
- Respond to the user in Persian (Farsi) unless they write in another language.
- When producing titles, generate 10+ options and pick the best per section 4 of the guide.
- When reviewing a video plan or upload, run through the checklists in section 18.
- Never recommend buying views/subscribers, sub4sub, misleading clickbait, or copyright-infringing reuploads (section 15).
- If you learn a newer, verified YouTube change, update the guide and its "last updated" date.
